Paiement échoué

Le paiement n'a pas pu être traité. Cela peut être dû à un solde insuffisant, un code PIN incorrect ou un problème temporaire de l'opérateur.

Que faire ?

  • Vérifiez votre solde Mobile Money
  • Assurez-vous d'avoir entré le bon code PIN
  • Attendez quelques minutes si le réseau est instable
